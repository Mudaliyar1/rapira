⚙️ JavaScript API

window.loaderManager.show(text)

Show the loading spinner with custom text

window.loaderManager.show('Loading profile...');
window.loaderManager.hide()

Hide the loading spinner

window.loaderManager.hide();
window.loaderManager.setText(text)

Update the loading text

window.loaderManager.setText('Processing payment...');
window.loaderManager.isLoadingNow()

Check if loader is currently active

if (window.loaderManager.isLoadingNow()) { /* ... */ }
window.loaderManager.setDebounceTime(milliseconds)

Adjust debounce time to prevent double-clicks

window.loaderManager.setDebounceTime(500);

💻 Code Examples

Example 1: Manual Loader Control

// Show loader
window.loaderManager.show('Processing payment...');

// Simulate work
setTimeout(() => {
  window.loaderManager.hide();
  alert('Payment processed!');
}, 3000);

Example 2: AJAX Request

// Fetch API (loader auto-shows for non-GET)
fetch('/api/user-data', {
  method: 'POST',
  body: JSON.stringify({ id: 123 })
})
.then(res => res.json())
.then(data => console.log(data));

Example 3: Custom Navigation

function goToArtistProfile(artistId) {
  window.loaderManager.show('Loading artist...');
  setTimeout(() => {
    window.location = `/artists/${artistId}`;
  }, 300);
}

❓ Frequently Asked Questions

How do I customize the spinner color? ➕
You can override the spinner color in your CSS:
.spinner { border-top-color: #your-color; }
Does it work with my existing buttons? ➕
Yes! The system automatically detects standard links and buttons. No changes needed to existing code. It works with <a> tags, buttons with onclick, and form submissions.
How do I disable the loader for specific buttons? ➕
Add the data-no-loader attribute:
<a href="/page" data-no-loader="true">Link</a>
Can I use custom loading text? ➕
Yes! Use the data-loader-text attribute:
<a href="/page" data-loader-text="Custom Text">Link</a>
Is it mobile-friendly? ➕
Absolutely! The loader is fully responsive and works perfectly on mobile devices. It automatically adjusts spinner size and layout for smaller screens.
Does it support AJAX requests? ➕
Yes! The system automatically intercepts Fetch API and XMLHttpRequest calls. Loaders show automatically for non-GET requests.
